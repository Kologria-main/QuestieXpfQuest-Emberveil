# Artwork

`icon.png` is original project artwork generated for KoQuest in 2026. It intentionally contains no text, copied game logo, protected character, or existing Questie/pfQuest/Emberveil mark.

Generation brief: a teal cartographic waypoint with a four-point compass over an original parchment map, in a dark navy/teal fantasy UI style. The icon is a square PNG and remains below Emberveil's announced 10 MB image limit.

`screenshots/` contains real in-game KoQuest screenshots recovered from the existing moderated addon page. See `docs/submission-assets.md` for the recommended upload order.
